One lab interface engine.

Vibe Lab Exchange is a free, open-source interface engine for clinical laboratories. It connects analyzers, LIS/LIMS, EHRs and other applications, and keeps a durable record of every message it handles, on a computer the lab owns.

Connect what the lab already has.

Channels pair a source with one or more destinations, with optional filters and transformations, configured without writing code.

Instrument interfaces
Receive results and send orders to analyzers over ASTM E1381/E1394 (CLSI LIS01-A2/LIS02-A2) on serial or TCP connections, plus vendor-specific protocols as they are added.
HL7 v2 interfaces
Exchange orders, results and patient demographics with LIS, LIMS, EHR and practice systems over MLLP. Each message keeps its acknowledgement history.
File interfaces
Import and export CSV and other delimited files from watched folders or on a schedule, for instruments and applications that only speak files.
Channels and transformations
Map fields, filter messages and route them to several destinations from one configuration, with versions kept for review.

A receipt for
every message.

An interface is only as trustworthy as its record. Vibe Lab Exchange is built around a durable message store and explicit failure states.

Durable by default
Every message received and sent is stored with its acknowledgements, retries and outcome. A transport acknowledgement is never mistaken for successful processing.
Explicit failures
Rejected, timed out and unknown outcomes are shown as such and can be reconciled, resent or closed with a reason.
Local by design
Runs on one laboratory computer on Windows, macOS or Linux. No server to run, no subscription, no cloud dependency for daily work.
